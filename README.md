# Simple chess gui programm.

This code is designed to build a simple graphical interface for interacting with the Stockfish chess engine.
The `Makefile` and `main.cpp` are intended for compilation on Linux (e.g., Debian).
The `main_win.cpp` and `file_win.sh` files are meant for compilation within an MSYS2 environment on Windows 10.
I don’t recall the exact list of components installed for static compilation, but you can install any missing dependencies by following the prompts provided in the compilation error messages.
